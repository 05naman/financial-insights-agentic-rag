# Frontend

React 19 + TypeScript + Vite + Tailwind 4. See [../docs/run-locally.md](../docs/run-locally.md) and [../docs/design.md](../docs/design.md).

```bash
cp .env.example .env     # VITE_API_URL=http://localhost:8000
npm install
npm run dev              # http://localhost:5173
npm test                 # Vitest
npm run build            # type-check + production build
```
